# 9. Системы аддона <span class="tag">Новое</span>

Общий принцип у торговцев аддона: обычный ПКМ - окно торговли (аддон дописывает в конец свои бесконечные сделки). Присесть + ПКМ с нужной вещью в руке - торговец называет цену или услугу; повторить присесть + ПКМ в течение 5 секунд - сделка.
