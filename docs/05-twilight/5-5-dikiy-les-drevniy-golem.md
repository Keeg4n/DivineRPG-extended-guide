# 5.5 Дикий лес: Древний голем <span class="tag">Новое</span>

<div class="note">Новый босс аддона.</div>

<b>Требуется броня R2.</b> Логово - Капище Дикого леса: кольцо мшистых менгиров, камни-укрытия, родники, алтарь. Здоровье 600: правая рука 120, левая рука 120, ноги 150, моховое ядро 210.

- Корпус не пробить, пока целы руки или ноги. Куда попал - та часть и получает урон; отбитая часть пропадает с модели.
- Пока есть руки: кулак, глыбы земли дугой, лиана издалека (подтягивает). Пока есть ноги: прыжок с топотом. Что отбил первым, то решает последнюю фазу: руки - лиановая буря, ноги - стая Вереков.
- Фазер бьёт по частям x2, сет Дикого леса x1.5 по частям. Слайсер в замах лианы перерезает её. Родники в сете Дикого леса лечат.
- Открывает: часы III, Камни врат, R3, Зелуса в Аркане.
