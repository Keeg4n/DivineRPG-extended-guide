# 5.3 Стражи рощ: общее <span class="tag">Новое</span>

- Логово - заповедная роща: большой остров высоко над остальными, одна на квадрат 640 x 640; у каждого мира своё святилище (5.4-5.7). Снизу остров оплетают извитые корни (не свисают сталактитами).
- Карта к заповедной роще = бумага + 8 фрагментов Эдема или у Странника за 2 камня.
- Зов стража: душа-рог-душа / душа-камень-душа / душа-печать-душа (6 душ мира, материал-"рог", камень мира, Печать святилища). "Рог": Эдем - Обломок рога Эдема, Дикий лес - Лунный рог, Апалачия - Сумрачный рог, Небесный терн - Небесная эссенция. ПКМ по алтарю рощи (заросший изумруд).
- Бить стража можно только с поляны.
- Добыча любого стража: Шестерня времени, Сердце стража, 4-8 душ мира.
