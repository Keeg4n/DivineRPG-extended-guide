# 6.1 Древний драмкрикс (город под храмом джунглей) <span class="tag">Новое</span>

<div class="note">Новый босс аддона.</div>

<table>
<tr><th>Где</th><td>Под ванильным храмом джунглей (и в джунглях Biomes O' Plenty) - заброшенный подземный город в куполе (радиус 72, свод до 34). Колодец храма продолжается башней со сплошной винтовой лестницей до пола, западнее арены. Арена в центре купола: круглая, мощёная, с колоннами и алтарём, по краю обвалившаяся ограда с четырьмя проходами. Вокруг - кольцевой бульвар с фонарями, дальше кольцом кварталы: заросшие дома, сады, сундук примерно в каждом третьем доме. Со свода растут корни раструбом, с лианами, часть светится на конце. Чужие враждебные мобы внутри не появляются.</td></tr>
<tr><th>Как найти</th><td>Карта к храму джунглей = бумага в окружении какао-бобов.</td></tr>
<tr><th>Вызов</th><td>Тотем Древнего драмкрикса на алтарь джунглей (изумруд в храмовом камне). Рецепт: самоцвет-осколок-самоцвет / осколок-камень джунглей-осколок / самоцвет-осколок-самоцвет.</td></tr>
<tr><th>Самоцвет джунглей</th><td>Из руды джунглей: только в биоме джунглей (высота 8-36). Её берёт только халитовая кирка или мультиинструмент - то есть после Вамашерона.</td></tr>
<tr><th>Характеристики</th><td>1500 здоровья, удар 20, не отбрасывается, модель драмикса x3 с маленькой золотой короной.</td></tr>
</table>

- Хвост: ближе 6.5 блока - замах 1 с, удар по кругу (14 урона, сильный отброс), раз в 5 с.
- Таран: дальше 8 - бег по прямой (18 урона); врезался в стену - оглушён 3 с, урон по нему x1.5.
- Споры: раз в 12 с под игроками светится место - через 1.5 с ядовитое облако. На половине здоровья зовёт 3 порабощённых драмкриксов: пока они живы, шкура держит 75% урона. Ниже 25% - ярость.
- Добыча: осколки и камни джунглей, изумруды, частичка души для Духа мира.
- Пасхалка: в особом доме города стоит диван с РПГ-7 - на нём можно сидеть (выключается настройкой easterEggs).
