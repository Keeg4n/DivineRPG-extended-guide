# 7.8 Бестиарий <span class="tag">Новое</span>

Книга Бестиарий (у Торговца скотом за книгу + 5 теневых монет): главы по мирам, карточки мобов с моделями. Сколько убить, чтобы моб считался изученным: частый - 10 (в главах Края, Арканы, Везеи - 5), редкий - вдвое меньше, очень редкий - вчетверо. Закрыл главу - Торговец скотом даст Знак охотника этого мира: урон по мобам +6% и их урон по тебе -5% везде, а в своём мире +15% и -12%. Знаки не складываются; встраиваются в шлем.
