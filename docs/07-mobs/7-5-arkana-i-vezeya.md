# 7.5 Аркана и Везея

<b>Аркана:</b> враги только из спавнеров в комнатах; в ближнем бою бьют арканным уроном - Гончая смерти (120 / 10), Дефкрикс (160 / 6), Подземельный заключённый (85 / 17, превращается в демона), Живая статуя (60), Разорбек (35 / 7), Бродяга (110 / 20). Роняют Коллекторы. Подземельного конструктора (100 / 19) вызывают заряженным коллектором, с него ключи.

<b>Везея:</b> мобы привязаны к этажам. 1 этаж (y 0-48): Кислотная ведьма, Симесоид, Дуо, Лорга, Шадахаер - грязный жемчуг. 2 этаж: Бифрон, Крушитель снов, Горгосион, Мандрагора, Близнецы, Верменус - очищенный жемчуг. 3 этаж: Богемит, Галроид (100 / 25), Казротик, Лхеива, Летающая лорга, Токаксин - полированный жемчуг. 4 этаж: Хелио (140 / 40), Вхраак, Зона, Зорагон, Диссимент - сверкающий жемчуг. Слабости особых мобов к виду оружия - 6.3.
